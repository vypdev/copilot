# Secret exposure rules

The implementation MUST:

- use `spawn` without a shell;
- keep credentials in environment variables only;
- avoid interpolating secrets into prompts or arguments;
- bound stdout and stderr;
- sanitize provider errors;
- map caught values to semantic errors before logging or publication;
- keep raw causes and stacks out of structured logs, Job Summaries, comments, and JSON output;
- never print authentication files, tokens, cookies, or connection strings;
- reject automated commits containing sensitive files;
- avoid uploading full workspaces or unbounded logs.

A suspected exposure is a terminal security failure. The run MUST stop and no commit, push, or finding publication may follow.
