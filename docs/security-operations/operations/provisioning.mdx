# CLI provisioning

When running in GitHub Actions, the Action provisions and verifies only the
selected runtime. `AGENT_PROVISIONING=auto` reuses a preinstalled executable only
after exact-version validation. If absent, Codex and OpenCode are installed with
the manifest-owned version through the runner's system `npm`. Cursor must be
preinstalled at the exact manifest version because its public installer cannot
guarantee an immutable historical version. The Action never uses `npx`, Yarn,
Bun, a floating tag, or an unpinned installer.

| Runtime | Provisioning source | Required pin |
| --- | --- | --- |
| OpenCode | `opencode-ai@1.18.3` through runner `npm` | Manifest `1.18.3` |
| Codex | `@openai/codex@0.153.4` through runner `npm` | Manifest `codex-cli 0.153.4` |
| Cursor | Controlled runner image | Manifest `2026.09.10-fd3934a` |

Provisioning failure is terminal. The Action MUST NOT install another runtime as a fallback.
