# Version pinning

The published Copilot package may be pinned for reproducible local tooling. The GitHub Action's selected agent CLI follows a simpler policy: use an available CLI, or install the current official standalone release if its default command is missing. There is no exact agent CLI version requirement.

| Runtime | Historical smoke baseline | Missing default command |
| --- | --- | --- |
| Codex | `codex-cli 0.156.1` | Official OpenAI standalone installer |
| OpenCode | `1.18.3` | Official standalone installer or Windows release archive |
| Cursor | `2026.09.10-fd3934a` | Official installer or Windows release archive |

The Copilot CLI is distributed as `@vypdev/copilot` and exposes the `copilot` executable. Pin it for reproducible local tooling:

```bash
VERSION=<known-good-version>
npm install --global "@vypdev/copilot@${VERSION}"
copilot --version
```

## Rules

1. Reuse an available selected CLI without replacing it or matching a fixed version.
2. Install only a missing default command from the selected provider's official source, in a private job directory.
3. Require a non-empty version and the normal guarded executable, command, and credential checks.
4. Never replace an explicitly selected executable or fall back to another provider.
5. Record only sanitized identity and failure category; keep credentials out of installer processes.

See [Provisioning](/security-operations/operations/provisioning) and [Upgrade and rollback](/security-operations/operations/upgrade-rollback) for the lifecycle procedure.
