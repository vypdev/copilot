# Pull Requests Configuration

These inputs apply when the action runs on `pull_request` events. For the complete list of all action inputs, see [Configuration](/configuration).

## Project and assignees

| Input | Description | Default |
|-------|-------------|---------|
| `project-ids` | Comma-separated GitHub Project IDs to link PRs to | — |
| `project-column-pull-request-created` | Column for newly created/linked PRs | "In Progress" |
| `project-column-pull-request-in-progress` | Column for in-progress PRs | "In Progress" |
| `desired-reviewers-count` | Number of reviewers to assign (max: 15) | 1 |

## AI (PR description and comments)

| Input | Description | Default |
|-------|-------------|---------|
| `ai-pull-request-description-mode` | `replace`, `append`, `preserve`, or `disabled`; controls automatic ownership and explicit `/copilot description` updates | `replace` |
| `repository-locale` | BCP-47 locale inherited by generated repository, issue, and PR messages | `en-US` |
| `pull-requests-locale` | Optional PR-surface override; empty inherits `repository-locale` | empty |
| `ai-members-only` | Restrict AI PR description to org/project members only | "false" |

See [AI PR description](/pull-requests/ai-description) for how the description is generated and [Agent CLI configuration](/agents/cli-configuration) for runtime and model setup.

Copilot preserves the original review comment byte-for-byte. For an addressed request in another language it performs one bounded adaptation before domain work, keeps commands and technical operands intact, and adds escaped translation context to the bot-owned response only when translation occurred.

## Other

| Input | Description | Default |
|-------|-------------|---------|
| `commit-prefix-transforms` | Transforms for commit prefix from branch name (e.g. `replace-slash`) | "replace-slash" |
| `token` | GitHub PAT (required for linking and project updates) | — |

For size thresholds, priority labels, and branch naming (used when the action infers the issue from the branch), see [Configuration](/configuration).

## Fixed linkage safety rules

PR-link recovery is intentionally not configurable. Repository identity and the
PAT are bound by the action runtime; capability requests contain neither. PR and
issue numbers must be positive safe integers, branch refs must be safe, and the
provider target is derived from the configured repository rather than an event
URL. The temporary marker format, default-branch observation delay, compensation
order, and exact-body restoration cannot be weakened by workflow inputs.
