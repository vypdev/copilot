# First pull request workflow

Use [Your first issue-to-PR workflow](/first-workflow) for the complete worked example after installation, including the exact branch, target, linked issue and current-revision checks. Use [Review PRs and resolve findings](/guides/review-pull-requests) to configure the review capabilities. The checklist below applies to an already installed PR workflow; it does not ask you to create another one.

<Steps>
  <Step title="Open a trusted pull request">Start with a branch and repository under your control.</Step>
  <Step title="Check workflow permissions">Grant only the permissions needed for the selected PR capability.</Step>
  <Step title="Run the workflow">Confirm checkout, agent policy, and provider preflight succeed.</Step>
  <Step title="Review the result">Verify description, comments, labels, or linked issue updates.</Step>
</Steps>

Do not expose write credentials to untrusted fork code. See [Pull Requests](/pull-requests) and [Trust boundaries](/security-operations/security/trust-boundaries).
