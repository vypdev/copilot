# First pull request workflow

<Steps>
  <Step title="Open a trusted pull request">Start with a branch and repository under your control.</Step>
  <Step title="Check workflow permissions">Grant only the permissions needed for the selected PR capability.</Step>
  <Step title="Run the workflow">Confirm checkout, agent policy, and provider preflight succeed.</Step>
  <Step title="Review the result">Verify description, comments, labels, or linked issue updates.</Step>
</Steps>

Do not expose write credentials to untrusted fork code. See [Pull Requests](/pull-requests) and [Trust boundaries](/security/trust-boundaries).
