# CLI provisioning

The Action provisions only the selected runtime when running in GitHub Actions. Versions MUST be explicit. It MUST use `pnpm`, never `npm`, `npx`, Yarn, Bun, or an unpinned installer.

| Runtime | Provisioning source | Required pin |
| --- | --- | --- |
| OpenCode | `opencode-ai@<version>` through Corepack pnpm | `OPENCODE_VERSION` |
| Codex | `@openai/codex@<version>` through Corepack pnpm | `CODEX_VERSION` |
| Cursor | Official installer with SHA-256 verification | `CURSOR_INSTALLER_SHA256` |

Provisioning failure is terminal. The Action MUST NOT install another runtime as a fallback.
