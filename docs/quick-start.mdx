# Quick start

## Prerequisites

You MUST have a GitHub repository, a fine-grained token stored as a repository secret, and a workflow that checks out the repository before invoking Copilot. Agent features additionally require either a verified CLI already installed on the runner or a pinned provisioning input. Codex may use the runner's preinitialized session instead of an exported credential.

## Minimal workflow

```yaml
name: Copilot
on: push
jobs:
  copilot:
    runs-on: ubuntu-latest
    permissions:
      contents: write
      issues: write
      pull-requests: write
    steps:
      - uses: actions/checkout@v4
      - uses: vypdev/copilot@v3
        with:
          token: ${{ secrets.COPILOT_TOKEN }}
          agent-provider: codex
          agent-model-provider: openai
          agent-model: gpt-5.6-luna
          agent-effort: medium
        env:
          OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}
```

The example uses the stable `v3` major ref. For strict reproducibility, replace it with an immutable release tag after selecting the version you have validated.

## Verify before enabling writes

1. Run the workflow with read-only permissions.
2. Confirm the selected agent CLI version and model allowlists.
3. Run the provider smoke procedure.
4. Grant write permissions only to the workflows that need commits or comments.

See [Configuration checklist](/configuration-checklist) and [Security](/security-operations/security/credentials).
