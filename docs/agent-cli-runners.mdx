# Agent CLI runners

Copilot has three provider contracts:

| Provider | Transport | Headless command | Status |
| --- | --- | --- | --- |
| OpenCode | server | managed OpenCode server | supported and tested |
| Codex | CLI | `codex exec --ephemeral --skip-git-repo-check -` | supported when the runner is provisioned and verified |
| Cursor | CLI | `agent -p --output-format text -` | supported when the runner is provisioned and verified |

The action never invokes a shell for agent commands. The prompt is sent through stdin and stdout is bounded and treated as untrusted provider output.

## Runner provisioning

Install the official provider CLI on every runner that will execute it. Do not add API keys to the repository, workflow YAML, action inputs, or command strings.

- OpenCode: provision the OpenCode executable or use the managed server lifecycle.
- Codex: install the OpenAI Codex CLI and authenticate through the runner environment.
- Cursor: install the Cursor CLI using the official installer at `https://cursor.com/install`, then authenticate with `agent login` or `CURSOR_API_KEY`.

Use environment references for credentials:

```text
Codex: CODEX_ACCESS_TOKEN or OPENAI_API_KEY
Cursor: CURSOR_API_KEY
OpenCode: provider-specific API key
```

## Verification

From the repository root, run:

```bash
node scripts/verify-agent-clis.cjs
```

A provider is operational only when the checker reports:

1. the executable is present on the runner;
2. its headless help command exits successfully;
3. the required credential reference is present;
4. a smoke execution has been performed in a non-production repository.

The checker prints only availability and credential-reference state. It never prints credential values.

## Workflow variables

The setup workflow templates accept:

```yaml
agent-provider: ${{ vars.AGENT_PROVIDER }}
agent-transport: ${{ vars.AGENT_TRANSPORT }}
agent-model: ${{ vars.AGENT_MODEL }}
agent-command: ${{ vars.AGENT_COMMAND }}
```

Defaults remain OpenCode server transport. To select Codex:

```text
AGENT_PROVIDER=codex
AGENT_TRANSPORT=cli
AGENT_COMMAND=codex exec --ephemeral --skip-git-repo-check -
```

To select Cursor:

```text
AGENT_PROVIDER=cursor
AGENT_TRANSPORT=cli
AGENT_COMMAND=agent -p --output-format text -
```

Run the verification checker on the exact self-hosted runner before enabling either provider. A configured workflow without a verified runner is not considered ready.
