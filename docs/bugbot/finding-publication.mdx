# Finding publication

Bugbot accepts only structured findings that pass schema, path, severity, duplicate, and comment-limit policies. For issue-only work, findings are published as issue comments. When a pull request is available, Bugbot publishes one GitHub review containing a review-level summary and all new findings as inline comments; it does not mirror those findings as independent pull-request conversation comments.

Each inline comment is anchored to a valid changed line. When the reported file is outside the pull-request diff, Bugbot uses the first available changed line and explains that fallback in the comment. If the pull request has no commentable diff line, the complete finding remains in the review summary.

Publication MUST complete before a finding is marked resolved. Invalid responses, unsafe paths, malformed identifiers, or publication failures are terminal for that finding and MUST NOT produce a false resolved state.
