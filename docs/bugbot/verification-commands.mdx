# Verification commands

`bugbot-fix-verify-commands` contains comma-separated commands such as:

```text
pnpm run build, pnpm test, pnpm run lint
```

Commands are parsed without a shell. Shell operators and empty commands are rejected. Commands run after the agent changes and before staging. If any command fails, the action MUST NOT commit, push, or mark findings resolved.

This repository's comment workflows prepare Node, pnpm and dependencies for configured verification when an explicit `fix`, `implement`, `remember`, or non-dry-run `sync-branch` command is requested. Learned-rule commits pass the same verification gate as other authorized file changes.
