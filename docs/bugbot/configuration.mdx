# Bugbot configuration

Bugbot uses the same explicit agent CLI contract as the other AI features. Configure the runtime, model provider, model, credentials, and policy separately.

## Agent runtime

```yaml
with:
  agent-provider: codex
  agent-model-provider: openai
  agent-model: gpt-5.6-luna
env:
  AGENT_ALLOWED_MODEL_PROVIDERS: openai
  AGENT_ALLOWED_MODELS: openai/gpt-5.6-luna
  OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}
```

For this configuration, Bugbot executes:

```text
codex exec --ephemeral --skip-git-repo-check -
```

`agent-provider` selects the CLI runtime. `agent-model-provider` and `agent-model` select the qualified model. Allowlists are checked before execution and failures are terminal. See [Agent CLI configuration](/agents/cli-configuration).

## bugbot-severity

**Default:** `low`

Minimum severity published as a finding comment.

| Value | Findings published |
| --- | --- |
| `info` | info, low, medium, high |
| `low` | low, medium, high |
| `medium` | medium, high |
| `high` | high only |

```yaml
bugbot-severity: medium
```

## bugbot-comment-limit

**Default:** `20`

Maximum number of individual finding comments published per target. Additional findings are summarized in an overflow comment. The implementation bounds this value; use a modest limit to avoid noisy issue or review threads.

```yaml
bugbot-comment-limit: 20
```

## bugbot-fix-verify-commands

**Default:** empty

Comma-separated commands run after an autofix or user-request change and before the Action commits and pushes. If any command fails, no commit or push occurs.

```yaml
bugbot-fix-verify-commands: "pnpm run build, pnpm test, pnpm run lint"
```

Commands are parsed without invoking a shell and unsafe shell operators are rejected. Keep commands deterministic and use `pnpm` for JavaScript/TypeScript projects.

## ai-ignore-files

**Default:** empty

Comma-separated paths or patterns excluded from Bugbot analysis and finding publication. This is an analysis/reporting filter; it is not a general write-protection mechanism for autofix or user-request workflows.

```yaml
ai-ignore-files: "build/*, dist/*, **/node_modules/**"
```

Use repository-specific review and protected-branch controls in addition to ignore patterns when limiting automated writes.

## Permissions and triggers

Detection is read-oriented, but publication requires the GitHub permissions needed to create issue comments or pull-request review comments. Autofix and user-request workflows additionally require write permission and must be restricted to trusted actors and trusted code.

Do not expose provider credentials to fork code, untrusted pull requests, or `pull_request_target` workflows that execute attacker-controlled code. Prefer private repositories, protected branches, reviewed workflows, approved environments, and controlled runners.

## Summary

| Input or variable | Default/recommended value | Purpose |
| --- | --- | --- |
| `agent-provider` | `codex` | Selects the CLI runtime |
| `agent-model-provider` | `openai` | Selects the model provider |
| `agent-model` | `gpt-5.6-luna` | Selects the model name |
| `AGENT_ALLOWED_MODEL_PROVIDERS` | `openai` | Provider allowlist |
| `AGENT_ALLOWED_MODELS` | `openai/gpt-5.6-luna` | Exact qualified-model allowlist |
| `bugbot-severity` | `low` | Minimum published severity |
| `bugbot-comment-limit` | `20` | Individual comment limit |
| `bugbot-fix-verify-commands` | empty | Pre-commit verification |
| `ai-ignore-files` | empty | Analysis/reporting exclusions |
