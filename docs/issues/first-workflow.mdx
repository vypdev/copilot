# First issue workflow

<Steps>
  <Step title="Create the issue">Use a supported issue type and required label.</Step>
  <Step title="Verify branch policy">Confirm the configured tree and branch naming rules.</Step>
  <Step title="Run the issue workflow">Trigger it from a trusted repository event.</Step>
  <Step title="Verify side effects">Check branch, project, labels, comments, and notifications.</Step>
</Steps>

See [Issue workflow setup](/issues/workflow-setup) for inputs and [Issues](/issues) for the complete capability map.
