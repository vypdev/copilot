# Testing OpenCode locally

Copilot uses OpenCode through its headless CLI. No OpenCode HTTP server is required for the current architecture.

## Prerequisites

1. Install the pinned OpenCode CLI.
2. Configure the model provider credential, if the selected provider requires one.
3. Use an explicit qualified model reference such as `openai/gpt-5.6-luna`.
4. Run only harmless prompts when testing.

## Verify the installation

```bash
command -v opencode
opencode --version
opencode run --help
```

From the Copilot repository, also run:

```bash
node scripts/verify-agent-clis.cjs
```

The verifier reports sanitized credential state and never prints secret values.

## Recommended smoke test

Only run this when the provider, credential, and possible usage cost are authorized:

```bash
printf '%s\n' 'Reply with exactly READY. Do not inspect or modify files.' \
  | timeout 120s opencode run --model openai/gpt-5.6-luna -
```

Expected evidence:

```text
READY
exit code: 0
```

The exact output formatting can include CLI metadata. The meaningful checks are that the explicit model was accepted, the response contains `READY`, and the process exits successfully.

## Testing a different provider

Use the same explicit form:

```bash
opencode run --model provider/model-id 'Reply with exactly READY.'
```

The provider/model reference must be allowed by the configured policy when the request is made through Copilot. Do not rely on a repository-local default, global OpenCode configuration, or interactive model selection.

## Troubleshooting

| Symptom | Check |
| --- | --- |
| `opencode: command not found` | Install the pinned CLI and verify `PATH`. |
| Authentication error | Confirm the provider's environment-backed credential without printing it. |
| Model rejected | Confirm the qualified `provider/model` reference and the allowlists. |
| Command rejected by Copilot | Keep `--model provider/model` in custom OpenCode commands. |
| Timeout | Retry only with an explicit, bounded timeout; do not add fallback providers. |

See [Agent CLI configuration](/agent-cli-configuration), [OpenCode (AI)](/opencode-integration), and [Agent CLI provisioning](/agent-cli-provisioning).
