# CLI commands

Provider argv is generated by trusted policy and is not a public configuration surface.

| Runtime | Managed shape |
| --- | --- |
| OpenCode | `opencode run --pure --agent <managed-role> --format json --model <provider>/<model> [--variant <effort>] <prompt>` |
| Codex | `codex exec --strict-config --ignore-user-config --ignore-rules --ephemeral --sandbox <mode> --model <model> ... -` |
| Cursor | `agent -p --output-format text --sandbox enabled --model <model> [--mode ask\|--force] <prompt>` |

The executable is called with `shell: false`. Codex receives the prompt over `stdin`; OpenCode and Cursor receive one final positional argument. Callers never provide these tokens. `agent-executable` can only select the expected bare basename or an absolute path with the same basename; arguments, wrappers, alternate basenames, relative paths, shell syntax, and environment prefixes are rejected.

Each invocation uses ephemeral mode-`0600` provider files whose hashes are rechecked immediately before spawn. The child environment starts from an allowlist, carries at most the selected control-plane credential, disables Git prompts and ambient Git config, and contains no GitHub, Git, SSH, cloud, proxy, or unrelated credential variables. Timeout/cancellation terminates the process group and removes only that invocation's owned runtime directory.

## Explicit issue and pull-request commands

Comments beginning with `/copilot` use a deterministic product-command boundary. These are product actions, not agent CLI argv.

| Command | Purpose | File mutation |
| --- | --- | --- |
| `/copilot plan` | Produce an actionable implementation plan. | No |
| `/copilot clarify` | List implementation blockers. | No |
| `/copilot estimate` | Estimate effort, risk, and validation. | No |
| `/copilot test-plan` | Propose a focused test strategy. | No |
| `/copilot status` | Summarize lifecycle and next step. | No |
| `/copilot description` | Generate or refresh the PR description. | PR body only |
| `/copilot review [effort=smart\|low\|default\|high] [dry-run=true]` | Review the current change. | No |
| `/copilot findings` | Summarize known Bugbot findings. | No |
| `/copilot recheck` | Analyze the current context again. | No |
| `/copilot fix FINDING-ID` | Fix one finding, or `all`. | Authorized workspace write |
| `/copilot dismiss FINDING-ID` | Dismiss a known finding. | Finding state only |
| `/copilot remember RULE` | Add a versioned learned rule. | Authorized workspace write |
| `/copilot implement REQUEST` | Apply an explicit repository change. | Authorized workspace write |

The product-command parser limits input size and argument count and rejects unknown commands. Agent output is untrusted and sanitized before publication.
