# Agent execution contract

A run MUST resolve one complete tuple before invoking a CLI:

```text
runtime = agent-provider
model = agent-model-provider/agent-model
effort = agent-effort
command = agent-command or the selected provider default
```

The tuple is invalid if any required field is empty, malformed, outside policy, or inconsistent with the selected provider. `effort` is optional; when present it is mapped to the provider's native reasoning/variant option, and is also included as a provider-neutral execution preference where the CLI has no native flag. Validation is terminal. The implementation MUST NOT infer a missing model from a provider default.

Every lifecycle role may override the complete tuple independently with `planner-*`, `findings-*`, `reviewer-*`, `fixer-*`, or `tester-*` inputs. Empty role fields inherit the common tuple. The selected runtime and model are resolved before an active task starts; inactive roles are neither provisioned nor authenticated.

The built-in role assignment is:

| Role | Responsibilities | Workspace mode |
| --- | --- | --- |
| `planner` | Help, recommendations, PR descriptions, plans, clarifications, estimates, and conversational answers | Read-only |
| `findings` | Push analysis, progress, issue-context review, and intent classification | Read-only |
| `reviewer` | Pull-request Bugbot analysis and review commands | Read-only |
| `fixer` | Explicitly authorized Bugbot autofixes and repository-change requests | Workspace write |
| `tester` | Test-plan commands | Read-only |

Structured tasks declare a JSON Schema. Copilot validates every structured response locally for every runtime and additionally passes a compatible managed schema to Codex through its native structured-output flag. Invalid, oversized, or prose-wrapped JSON fails instead of being guessed or partially accepted.

The contract is defined by `action.yml`, resolved by the input builder, authorized by the configuration policy, and executed by provider-specific adapters. See [Agent input reference](/agents/input-reference).
