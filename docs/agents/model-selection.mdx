# Model selection

Set the provider and model independently:

```yaml
agent-model-provider: openai
agent-model: gpt-5.6-luna
```

The effective qualified model is `openai/gpt-5.6-luna`. The provider prefix MUST NOT be duplicated in `agent-model`. A blank or malformed value fails before the CLI starts.

Set the optional effort or provider-specific variant explicitly when the selected model supports it:

```yaml
agent-effort: high
```

Codex maps this to `model_reasoning_effort`; OpenCode maps it to `--variant`. Cursor receives the preference in the execution context because its documented headless parameters expose model selection but no standard effort flag. Findings and fixer can use `findings-model-provider`, `findings-model`, `findings-effort` and their `fixer-*` equivalents.

Changing the model MAY change cost, quota, latency, and data-processing behavior. Treat a model change as an operational change requiring verification.
