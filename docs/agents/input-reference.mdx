# Agent input reference

## Selection inputs

| Input | Required | Effective default | Meaning | Secret |
| --- | --- | --- | --- | --- |
| `agent-provider` | No | `codex` | Runtime: `codex`, `opencode`, or `cursor` | No |
| `agent-model-provider` | No | `openai` | Provider serving the selected model | No |
| `agent-model` | No | `gpt-5.6-luna` | Model without provider prefix | No |
| `agent-effort` | No | empty | Supported reasoning effort or variant | No |
| `agent-executable` | No | Manifest basename | Exact basename or absolute path to that basename | No |

Each task supports the corresponding `findings-*`, `fixer-*`, `planner-*`, `reviewer-*`, and `tester-*` overrides, including `*-executable`. Empty role overrides inherit the common selection. There is no input for command text, arguments, sandbox, permissions, network, plugins, MCP, subagents, environment, persistence, limits, or versions.

The qualified model is `<agent-model-provider>/<agent-model>`; the default is `openai/gpt-5.6-luna`.

## Authorization variables

| Variable | Example | Meaning |
| --- | --- | --- |
| `AGENT_ALLOWED_MODEL_PROVIDERS` | `openai` | Comma-separated provider allowlist |
| `AGENT_ALLOWED_MODELS` | `openai/gpt-5.6-luna` | Exact qualified-model allowlist |
| `AGENT_PROVISIONING` | `auto` | `auto`, `always`, or `disabled`; versions remain manifest-owned |

Allowlists authorize a selection; they do not select runtime, model, executable, or credential.

## Authentication variables

| Runtime/provider | Credential reference |
| --- | --- |
| OpenCode using OpenAI | `OPENAI_API_KEY` or a controlled local provider login |
| Codex | `OPENAI_API_KEY`, `CODEX_API_KEY`, or a controlled local Codex session |
| Cursor | `CURSOR_API_KEY` |

Values must be supplied through the runner's secret/environment mechanism and scoped to the action step. Never put them in `with`, prompts, repository files, or logs.

## Exact runtime manifest

| Runtime | Executable | Accepted version |
| --- | --- | --- |
| OpenCode | `opencode` | `1.18.3` |
| Codex | `codex` | `codex-cli 0.153.4` |
| Cursor | `agent` | `2026.09.10-fd3934a` |

Codex and OpenCode may be provisioned at their manifest versions. Cursor must already be installed at the exact version because its public installer cannot guarantee an immutable historical version. Repository variables cannot override this manifest.

## Configuration ownership

- `action.yml` declares public inputs.
- `setup/workflows/*.yml` maps repository Variables.
- The input builder resolves structured values and precedence.
- The exhaustive provider dispatcher owns argv and authority.
- The execution planner owns executable/version/workspace/artifact preflight.
- The generic process adapter consumes only an admitted plan.

A contract change must update these surfaces, tests, the SDD, and catalog evidence together.
