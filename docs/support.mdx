## Ask a question or report a problem

Search [existing issues](https://github.com/vypdev/copilot/issues) first. If the
problem is with Copilot itself, use the appropriate installed form under
[New issue](https://github.com/vypdev/copilot/issues/new/choose): Help for a
question, Bug Report for a reproducible failure, or Documentation Update for
missing or unclear instructions. Complete all required fields.

Include:

| Evidence | What to provide |
|---|---|
| Versions | `copilot --version` and the Action ref in the affected workflow |
| Environment | OS, Node version, runner route, and web or terminal mode |
| Reproduction | Exact non-secret command or GitHub event, steps, expected result and actual result |
| Revision | A safe issue/PR/run link and the exact relevant commit, if shareable |
| Diagnosis | Stable error code, diagnostic reference and sanitized doctor/Job Summary output |
| Partial work | Which files/resources completed, were retained or need inspection |

Never include PATs, API keys, authentication files, pairing codes or a captured
credential field. Inspect logs and screenshots before sharing; private repository
names and configuration can also require redaction. Preserve uncertain resources
until you have inspected them rather than rerunning Apply blindly.

For a repository-specific task, use that repository's installed Issue Form and
bot commands. A branchless Help issue can answer questions; implementation needs
an admitted branch-bearing issue and its Action-verified ref.

## Security reports

Do not publish sensitive vulnerabilities or credentials in an issue. Contact the
maintainer privately at [efraespada@vyp.dev](mailto:efraespada@vyp.dev) with a
redacted description before arranging any sensitive evidence exchange.

## Contribute or follow changes

Use [CONTRIBUTING.md](https://github.com/vypdev/copilot/blob/master/CONTRIBUTING.md)
for development prerequisites and checks, and [repository collaboration](/agents/repository-collaboration)
for this project's Action-managed issue/branch flow. Submit documentation changes
with the same route and verification expectations.

Follow [GitHub Releases](https://github.com/vypdev/copilot/releases) for published
changes. This page does not promise a response deadline or require an external
community account to obtain support.
