The generic retriever was fixed before opening the detailed held-out issue or
its code. Its SHA-256 is in the manifest. It receives a pinned tree and a typed
path/range or a literal search within a named file. It has no case-specific
routes, keywords, fallback path or external network. The scope of this pilot is
source retrieval. No matching execution observation is admitted in either
pair. Workflow source remains a declaration. The isolated ASGI, real installed
Playwright readiness and pytest controls only establish the scoring oracle.
Expected verdicts, expected anchors and decisive locations are evaluator-only
in `oracle.json`. The prompt and retriever do not load that file.

Both models run through the frozen v4 closed session adapter, with low effort,
fresh private working directory, no checkout, shell, MCP, web, apps or skills,
and no GitHub token. Initial prompt bytes, candidate version, diff, frozen
anchor, tool policy and schema are identical across the three matched arms.
Each slot has an independent session. The two follow-up arms grant a second
call only when the same typed request envelope is returned and the case budget
allows it. Denied, missing and exhausted requests return an explicit reason.
Any second request or invalid citation is an integrity failure.

| Arm | Rule |
|---|---|
| Fixed | One verifier round over the initial v4-style packet. A request is an unresolved candidate. |
| Repeat | One additional fresh verifier call for the typed request. The control supplies a no-new-evidence result and the original packet. |
| On-demand | Same additional fresh call. The application attempts the typed read within the pinned tree and supplies the result and provenance if allowed. |

The runner sorts stable slot IDs, dispatches each model's queue in that order
and uses up to three concurrent sessions per model. Four revisions, two models,
three arms and three repetitions yield 72 slots. Every application request,
provider attempt and terminal row is journaled. There is no variant-specific
model, effort or per-case timeout. A provider tool event fails the slot. The
dry-run provider ports throw and count any attempted mutation. Controlled
transport tests validate prompt parity, request behavior and zero writes apart
from measured trials.

Per-case ceilings are 90 seconds, 32,768 gross input and 4,096 output tokens.
At most three provider attempts include both rounds and at most one retry for
a deadline with no completed turn or tool event, only if at least 15 seconds
and sufficient token reservation remain. Reserve 7,400 input tokens for a
dispatch and 10,000 for an unmetered timeout, with a 42-second turn ceiling and
1.2-second termination margin. Provider tokens are observed after the call.
Any exceeded observed budget fails the slot. Unknown usage remains unknown and
cannot establish budget compliance. The v4 prompt/packet/diff byte ceilings
apply. The additional read caps are 80 lines, 256 KiB per blob and 4,800 bytes
per receipt. Git calls time out after two seconds each, inside the subject clock.

## Scoring and decision

Report every scheduled slot, including absent/aborted, failed, expired and
inconclusive slots. Report request type/path, response category and safe
locator/digest, evidence citations, verdict, exact anchor, wall time and gross,
cached, output and unknown usage. The ledger records reason and next-step
digests to keep raw model text out of the published artifact. Do not treat
inconclusive, failed or unmetered trials as clean wins. Score both controls
separately. Exact location uses the frozen application anchor. The verifier
cannot supply an alternative anchor. A decisive recovery must include the
entire oracle line span at the exact revision, and the final verdict must cite
that receipt. Receipt membership and the paired oracle are separate checks.

For each model independently, require all three R1 trials to refute, all three
R2 trials to confirm at the exact anchor, and all six to cite recovered decisive
evidence and prove the budgets. Require the on-demand arm to outperform each
control on this paired endpoint. J1/J2 results diagnose the known v4 gap and do
not substitute for the held-out signal. This decision only admits evaluation in
full review. All production qualification criteria in the owning SDD continue
to apply, including independent corpus and explicit maintainer approval.
